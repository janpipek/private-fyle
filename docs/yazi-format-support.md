# Yazi format handling (research note)

Checked against Yazi's [default configuration at `ffb2e78`](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml) and its [installation guide](https://yazi-rs.github.io/docs/installation/) on 2026-10-14. These are *dispatch rules*, mostly by detected MIME type, not a promise that every file matching a wildcard decodes. Yazi requires `file(1)` for type detection and its [diagnostics show `file -bL --mime-type`](https://github.com/sxyazi/yazi/issues/3596); the resulting MIME type selects opener and preview rules. Other external programs must be installed for their corresponding handlers. The terms below distinguish preview from opening or extraction.

| File category | Default preview route and implementation | Opening or extraction |
| --- | --- | --- |
| Text/code | `text/*`, plus `application/mbox`, JavaScript, and Wine INI use the `code` previewer (Yazi's built-in code preview). JSON and NDJSON use `jq` for colored/indented preview and fall back to code preview if `jq` fails. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L117-L187), [JSON plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/json.lua) | Text and the listed application code types go to `$EDITOR` by default. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L31-L95) |
| Raster images | `image/*` uses Yazi's image preview. The bundled `image` crate enables BMP, DDS, OpenEXR, Farbfeld, GIF, HDR, ICO, JPEG, PNG, PNM, QOI, TGA, TIFF, and WebP decoders. AVIF, HEIF/HEIC, and JPEG XL (`image/{avif,hei?,jxl}`) are routed through ImageMagick instead. This MIME routing does not make every `image/*` subtype decodable. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L145-L179), [crate features](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/Cargo.toml#L57), [image adapter](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-adapter/src/image.rs), [ImageMagick plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/magick.lua) | `image/*` is handed to the OS opener. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L64-L95) |
| SVG | `image/svg+xml` is rasterized using `resvg`. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L145-L179), [SVG plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/svg.lua) | OS opener under `image/*`. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L64-L95) |
| Video | `video/*` makes a thumbnail/keyframe using `ffmpeg` (and metadata via `ffprobe`); scrolling changes the frame position. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L145-L179), [video plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/video.lua) | Audio and video are sent to the OS opener by default; Yazi does not itself decode audio for preview. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L31-L95) |
| PDF | `application/pdf` pages are rendered with `pdftoppm` into cached JPEGs; scrolling moves page by page. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L171-L193), [PDF plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/pdf.lua) | Falls through to OS opener. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L64-L95) |
| Fonts | `font/*` and `application/ms-opentype` make an alphabet/sample image through ImageMagick. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L171-L198), [font plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/font.lua) | Falls through to OS opener. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L64-L95) |
| Archives and package files | Archive preview covers MIME names matching `application/{zip,rar,7z*,tar,gzip,xz,zstd,bzip*,lzma,compress,archive,cpio,arj,xar,ms-cab*}`, plus Debian packages, RPM, and Android APK (`application/android.package-archive`). It lists contents with `7zz` or `7z`; compressed tarballs are piped through 7-Zip for an inner listing. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L178-L191), [archive plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/archive.lua) | The first MIME group gets an Extract command, using `7zz` or `7z`, including a password prompt when needed. Package files are previewed but have no matching default extract opener rule, so they go to the OS opener. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L64-L95), [extract plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/extract.lua) |
| AppImage and disk images | AppImage by filename; ISO, QEMU disk, WIM, Apple disk image, VirtualBox VHD/VHDX by MIME; and `*.{img,fat,ext,ext2,ext3,ext4,squashfs,ntfs,hfs,hfsx}` by filename are routed to the same 7-Zip archive lister. Actual success depends on 7-Zip's ability to read the file. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L184-L191), [archive plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/archive.lua) | Falls through to the OS opener, since these preview rules have no corresponding default extract opener rule. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L64-L95) |
| Unknown files | The fallback preview runs `file -bL` for a file-type description, not its content. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L198-L210), [file plugin](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-plugin/preset/plugins/file.lua) | Default OS opener. [Rules](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L64-L95) |

The [Yazi installation guide](https://yazi-rs.github.io/docs/installation/) explicitly identifies `ffmpeg`, 7-Zip, `jq`, poppler, `resvg`, and ImageMagick as optional tools for these previews. The preset's `spotters`, `preloaders`, and `previewers` are separate: spotters show metadata, preloaders build/cache images, and previewers draw the preview; an icon association or OS opening rule is not itself a content preview. [Default configuration](https://github.com/sxyazi/yazi/blob/ffb2e78cc70341946c04befa52e14a4494015ce8/yazi-config/preset/yazi-default.toml#L117-L210), [configuration documentation](https://yazi-rs.github.io/docs/configuration/yazi/#plugin).

## Compared with Fyle

Fyle's F3 registry currently has native previews for PDF, common images and embedded-JPEG camera RAW, audio/video, DOCX/ODT, spreadsheets, notebooks, Parquet, GPX/FIT, CSV/TSV, Markdown, text and a hex fallback. Its archive panel browses zip, tar and tar.gz as read-only directories. See [preview registration](../src/preview.rs), [image extensions](../src/preview/image.rs), [thumbnail extensions](../src/thumbnails.rs), [archive formats](../src/archive.rs) and the [behavior guide](../README.md).

The verified default-preview gaps relative to Yazi are:

| Category | Fyle today | Yazi mechanism |
| --- | --- | --- |
| DDS, EXR, Farbfeld, HDR, PNM, QOI and TGA images | No dedicated F3 image preview or icon thumbnail; files fall to text or hex. | Enabled decoders in its `image` crate, selected by MIME. |
| AVIF, HEIC/HEIF and JPEG XL images | Image icon, but no dedicated F3 preview or thumbnail. | ImageMagick converts them to a cached image; requires an installed ImageMagick with matching codec support. |
| Fonts | Font icon, but only hex/text fallback in F3. | ImageMagick draws a specimen for `font/*` and OpenType MIME. |
| Additional archives and packages | 7z, RAR, tar.bz2/xz/zst, CPIO, ARJ, XAR, CAB, DEB, RPM and APK are not browsable by the archive panel. | 7-Zip lists contents in the preview pane; supported archive MIME types can also be extracted. The Yazi preview is a listing, not navigation into an archive as a panel directory. |
| AppImage and disk images | No content listing. | 7-Zip listing where its decoder supports the file. |
| JSON/NDJSON formatting | F3 shows highlighted source text. | `jq` produces formatted, colored text, with a code-preview fallback. |

Fyle already previews SVG through GPUI and video frames through ffmpeg, so those are not format gaps. Yazi's scroll-to-frame video preview and page-by-page PDF scrolling are interaction differences; Fyle has a fixed video frame and Previous/Next PDF pages. See [media preview](../src/preview/media.rs), [PDF preview](../src/preview/pdf.rs) and [open follow-ups](../TODO.md).

Fyle's type handling is currently split: [Open With MIME detection](../src/mime.rs) reads shared-mime-info filename globs without content sniffing, [icons](../src/icons.rs) use names/extensions, and [F3 preview](../src/preview.rs) uses extensions and a few signatures. A shared detection result could feed these consumers while allowing platform-specific detectors and a filename-only fallback for unreadable or remote content. The unresolved policy for ambiguous text and remote files is tracked in [TODO.md](../TODO.md).
