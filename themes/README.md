(<https://github.com/longbridge/gpui-kit/tree/v0.7.0/themes>, tag `v0.7.0`),
which distributes them under the Apache License 2.0 (see
[`LICENSE-APACHE`](LICENSE-APACHE), Copyright 2024 - 2026 Longbridge).

Most are ports of third-party colour schemes; the original author and source
recorded in each file are listed below.
