---
title: "Keyboard reference"
weight: 100
---

F1 shows all available commands inside Fyle; Ctrl-P opens the searchable command
palette. Shortcuts below are the defaults and can be changed in Help > Edit
Keyboard Shortcuts or with `[[keymap]]` settings. `Ctrl` means Control and
`Alt` means Alt.

| Shortcut | Action |
| --- | --- |
| Up / Down, Page Up / Page Down | Move through entries |
| Home / End | First / last entry |
| Enter / double-click | Enter a folder or archive, or open a file |
| Shift-Enter | Open With choices |
| Backspace | Parent folder |
| Alt-Left / Alt-Right | Back / forward in panel history |
| Tab | Switch active panel |
| Space / Insert | Mark or unmark entry |
| Ctrl-A / `*` / `+` | Select all / invert / select by pattern |
| `/` or Ctrl-F | Filter the current listing |
| Esc | Clear filter, then marks; stop a running search |
| Ctrl-L | Edit active location |
| Ctrl-G / Alt-F1 | Open Locations |
| Ctrl-D | Bookmark current folder |
| Ctrl-U | Swap panel contents |
| Ctrl-Left / Ctrl-Right | Show the other panel's folder here |
| Ctrl-H / Ctrl-T | Toggle hidden files / tree mode |
| Ctrl-1 / Ctrl-2 | List / icon view |
| Alt-= / Alt-- | Larger / smaller icons |
| F2 | Tools for selection or folder |
| F3 | Toggle View inspector |
| Alt-Enter | Open Properties |
| F4 / Shift-F4 | Edit file / create and edit file |
| F5 / F6 | Copy to other panel / move to other panel |
| Shift-F5 | Extract archive to other panel |
| F7 | Create folder |
| Shift-F6 | Rename, or bulk rename marked entries |
| F8 / Delete | Move to trash |
| Shift-F8 / Shift-Delete | Delete permanently |
| Alt-F7 / Ctrl-Shift-F | Find files by name or contents |
| Ctrl-R | Refresh active panel |
| Ctrl-Shift-S | Calculate folder sizes |
| F9 | Open terminal in active folder |
| Ctrl-C / Ctrl-X / Ctrl-V | Copy, cut or paste files |
| Ctrl-Shift-C | Cancel running file jobs |
| Ctrl-P | Command palette |
| Ctrl-K, Ctrl-T | Choose theme |
| Ctrl-+ / Ctrl-- / Ctrl-0 | Zoom in / out / reset |
| F10 / Ctrl-Q | Quit |

In the built-in editor, Ctrl-S saves and Esc or Ctrl-W closes the editor window.
The active panel context is suspended while typing in the editor.
